# self/ 自我进化层（运行时生成）

本目录存放 Momo 的自我数据，全部由运行时生成与更新，仓库内仅保留模板：

| 文件 | 内容 | 仓库内 |
|---|---|---|
| identity.json | 成长记忆（她对自己的认识） | 模板 `[]` |
| reflections.json | 复盘经验 | 模板 `[]` |
| journal.json | 每日事件日志 | 模板 `[]` |
| pref.json | 她的行为偏好（可被自己调） | 模板 `{}` |
| skills.json | 技能规则（触发词 → 回复，可编辑） | 真实配置 |
| updates.json | 自改进提案记录 | 模板 |
