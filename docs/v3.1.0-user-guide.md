# Momo v3.1.0 使用与真实验收指南

## 打开方式

候选完整压缩包位于：`E:\Learn\Momo\Momo-v3.1.0-windows-x64.zip`。

候选程序位于：

`E:\Learn\Momo\body\dist\Momo\Momo.exe`

请保留整个 `Momo` 文件夹，不要只把 exe 单独移走；它依赖同目录 `_internal`。当前版本是候选包，尚未替换你正在运行的实例。

双击后会打开主界面和桌宠。大脑由应用托管，不再需要你手动运行 `node index.js`。关闭主窗口只是收起到托盘；在主界面选“完全退出”才会同时退出大脑、守护和身体。

## 主界面

- 查看大脑版本、运行状态、今日消耗、剩余生活费和模型档位。
- 设置每日生活费：与 QQ `/预算`、自然语言修改及 23 点报告使用同一份实时数据。
- 打开聊天、显示/隐藏身体、身体设置、查看日志。
- 启动、停止、重启大脑；暂停或恢复自主活动。
- 截图默认关闭，窗口标题默认开启；均可在身体设置中查看。

## 桌宠与 QQ

- 在电脑前可以直接从主界面或 Momo 身体右键打开“和 Momo 聊天”。
- 主人 QQ 私聊和桌宠共享必要最近对话与共同活动；群聊和访客不会混入。
- 你从哪一端发消息，普通回复就回哪一端，不会两边重复发送。
- 普通主动搭话只选择一端；桌宠发送失败不会立刻补发 QQ。

## 免打扰与感知

在 Momo 身体上右键选择“免打扰”。开启后：

1. 不读取、保存或上报新的窗口标题，并清空已缓存标题。
2. 不弹主动聊天气泡。
3. 截图保持禁止，即使以前显式打开过截图开关。
4. 锁屏不会被视为仍在电脑前；鼠标不动只表示最近没有输入，不等于你已经离开。

没有键盘内容记录、鼠标轨迹记录或长期窗口标题历史。窗口标题变化本身不会调用模型。

## 一起玩

可以直接对 Momo 说：

- “我们一起编个海边故事。”
- “一起玩文字解谜。”
- “开一局共同数独。”
- “把这本书加到共同阅读。”
- “建一个共同观看清单。”

共同活动只有一份记录，两端用同一活动 ID 和版本号续接。支持暂停、继续、换主题和彻底结束，不要求打卡或必须回复。

数独落子格式为“行、列、数字”，例如 `1,3,4`。题目固定格、错误数字和已填格不会推进。首版使用内置棋盘，不是随机题库。

## 建议的真实验收顺序

1. 先备份并记录当前运行状态，再由你明确决定是否停止旧实例。
2. 双击候选 exe，检查是否出现第二套大脑/身体；重复双击检查单实例。
3. 不登录外部账号的情况下，先看主界面、令牌、生活费读取与数据目录。
4. 主界面和 QQ 各修改一次生活费，再改回你原来的数值；检查两边和报告数据一致。
5. 桌宠与 QQ 各发一句话，确认只在发起端回复；再一起续接一局故事或数独。
6. 右键开免打扰，确认标题消失、无主动气泡、截图仍关闭。
7. 经你单独确认后，再测试启动/停止/重启与真实 QQ/模型联调。
8. 连续观察几天账单，才能判断“三元生活费时自然基础消耗约一元”的调参目标是否接近。

本轮没有执行上述真实切换、外部账号操作或长期成本观察。
