## 2. 主要落地

### 应用化

- 新增 `body/app_window.py`：状态、聊天、身体显示、启动/停止/重启、暂停自主活动、日志、明确退出。
- 新增 `body/chat_window.py` + `body/brain_api.py`：桌宠文字聊天复用本机大脑，不另存 API Key；聊天带 event_id。
- `body/main.py` / `tray.py`：主界面与聊天入口接入托盘和身体右键；关窗默认留托盘。
- 进程匹配限定当前 Momo 根目录，避免误伤其他项目的守护或 Node 进程。
- `supervise.ps1` 改为相对根目录并寻找可用 Node；仍由现有守护托管，未另造一套进程管理。
- `body/cfg.py` 在打包后向上寻找含 `index.js` 与 `plugins/` 的大脑根目录，避免写入 `dist/data`。

### 共同生活与双端

- 新增 `plugins/companion-service.js`：只允许主人 QQ 私聊与本机桌宠进入共享空间，群聊/访客失败关闭。
- 最近必要对话、共同活动与“不再提起”共享；普通回复仍只回发起渠道。
- 活动统一 `activity_id/version/state/turn/progress/channel`；支持开始、推进、暂停、续接、换主题、结束。
- 版本冲突拒绝旧写；Momo 回复成功写入会话后自动交还活动轮次。
- 首批活动：轮流故事、文字解谜、共同数独、共同阅读、共同观看清单。
- 数独为本地可校验棋盘：固定格/错误数字/重复格不推进，正确落子才写进度。
- 普通主动消息已接入真实发送链：桌面可用选桌宠，否则选 QQ；桌面失败不立即补发 QQ，桌宠回合不另发 QQ 表情。

### 陪伴与自主性

- 本地识别 chat/listen/quiet/play/solve，仅用于提示词约束；不替代模型理解。
- 明确允许短回复、自然收尾与安静陪伴，不加入打卡、亲密度、回复义务或情感惩罚。
- 主界面可暂停/恢复自主活动；`life-service` 的内部动作和主动消息都检查同一实时开关。
- 未提高自主等级，未扩大自修改权限，高风险硬边界继续沿用 v3.0。

### 感知与隐私

- 截图默认完全关闭；即使曾显式开启，免打扰时也拒绝截图。
- 窗口标题默认开启；免打扰或锁屏时不调用前台标题读取，并清空已缓存标题。
- 自动免打扰时段变化也会发布隐私状态，并非只有手动点击才生效。
- 免打扰不弹主动气泡；身体右键可直接切换。
- 锁屏优先判 `locked`；无输入只表示最近无键鼠活动，不断言主人离开。
- 不新增键盘内容、鼠标轨迹或长期标题历史；标题变化不触发模型。

### 统一预算与自然消耗

- 主界面、`/预算`、自然语言 `set_budget` 均走 `applyBudgetChange`。
- 修复旧实现更换 `cfg` 对象导致插件可能持旧引用的问题；现在保持对象身份并实时重算档位。
- 调整记录写入 `budget-adjustments.jsonl`；日报通过预算服务 API 读取，不直接解析配置字段。
- 23 点报告读取生成时额度、实际消耗及本周期调整。
- 主界面管理接口使用独立本机 token；身体与大脑首次启动可安全共用同一 token。
- 保留原有硬上限与逐级降级，没有“无互动日”或一元硬配额。
- 内部动作尝试日上限从 6 调为 4，标题变化等本地状态不调用模型；长期自然日约一元仍需真实账单观察，不能由单元测试证明。

## 5. 已知限制

- 本版没有把语音和嘴型同步作为门槛。

- 数独首版使用内置可校验棋盘，不是随机题库。
- 打包目录约 129 MB，exe 必须与同目录 `_internal` 一起保留；素材仍使用项目 `body/assets`。
- 真实“自然基础消耗约一元”只能作为调参目标，需账单验证，不作硬性保证。
