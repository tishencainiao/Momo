## 3. 明确的限制（不要对外声称有）

1. **没有真口型**：106 段素材里没有口型动画。说话 = 说话类动画 + 气泡 + 音频，不是对口型。
2. **不是时刻看着屏幕**：v0.4 的识屏是「该看的时候看一次」（大脑触发 + 限频），不是持续监控。
3. **不接管旧桌宠**：旧桌宠继续独立运行；新身体不会控制它，也不会读它的私有状态来做动作。
4. **素材非商用**：见 [body-attribution.md](body-attribution.md)。
5. **托盘管的是「本机进程」**：停止大脑会连守护一起停，Momo 就不再回 QQ 消息；托盘不会替代 supervise.ps1 的崩溃自愈能力（那仍由守护提供）。
