# Momo v3.0.0「连续存在与受限自主生长」总计划

> 基线：当前工作区 v2.2.3（实施前重新读取，非沿用旧总结）
>
> 目标：以一份总计划连续完成可信行动、认识沉淀、稳定自我、生活节律与受限自主生长。
>
> 自主性上限：**低风险可自主，高风险受硬边界约束。**
>
> 状态：主刀实施与模拟自测完成（98/98 测试文件、56 插件全绿）；待 DSH 独立验收与真实启动证据。验收记录见 `docs/v3.0.0-validation.md`；未标 candidate_ready / validated。

## 一、最终闭环

感知经历 → 保存可靠事实 → 消化为带证据的认识 → 修订分层自我 → 生成有限日常目标 → 持久化行动意图 → 执行并验证 → 复盘结果 → 调整后续认识与节律。

“行为涌现”只评价未硬编码的新目标/工具组合是否有证据、是否有效；不承诺意识，不把随机行为称为涌现。

## 二、保留并复用的现有能力

- `conversation-recovery`：会话事件身份、状态机、跨渠道恢复。
- `memory-digest`：稳定证据键、事务 manifest、scope 失效校验、digest-CTX 版本消费。
- `action-state.json` / `actions.jsonl`：begin/end/verify、抢占幂等、重启对账。
- `mind` / `proactive`：思考、候选动作、主动消息及既有冷却。
- `evolution` / `plugin-host`：self-* 静态校验、最小权限 ctx、观察与回滚。
- `health`：能力健康而非进程健康。

不新建平行大脑，不重复迁移旧记忆，不批量重写真实数据。

## 三、新增三个补层

### 1. action-intents：持久行动意图

文件：`data/action-intents.json`。

字段：intent_id、action_key、kind、risk、actor_scope、privacy_scope、reason、payload_summary、created_at、valid_until、status、attempts、last_error、result_evidence。

状态：ready → running → succeeded/failed/unknown；另有 expired/cancelled。

- 意图先落盘，再允许执行。
- 非幂等动作结果不明不自动重放。
- 过期意图不补发；重启只恢复明确可安全恢复的类型。
- 已有 recordAndSend/qzone 等账本继续负责真实执行，意图层只跟踪，不重复抢占同一 action_key。

### 2. continuity-service：认识、分层自我与复盘

文件：`data/continuity/beliefs.json`、`identity.json`、`revisions.jsonl`。

认识字段：belief_id、scope、statement、evidence_ids、confidence、status、valid_until、supersedes、created_at、confirmed_at。

- 只从 memory-digest 的 stable 证据组形成认识。
- 私聊、群、local 不互相背书。
- 明确修订保留 supersedes 链；冲突未解决时标 contested，不注入决策上下文。
- 自我分 core/slow/fast：core 不可自改；slow 需多条证据并保留修订；fast 有有效期。
- 上下文只使用 active 且未过期的认识，按 scope 过滤。

### 3. autonomy-service：自主等级与硬边界

文件：`data/autonomy.json`。

等级：0=暂停自主行动；1=只产提案；2=低风险自动。

硬规则：

- 高风险发送权限、config/apiKey/settings、核心文件、权限/回滚机制变更必须主人批准或被拒绝。
- 自主等级只能由主人通过命令修改。
- 自修改仅允许新 self-* 插件；低风险自动前必须有静态检查、隔离 manifest 冒烟和健康门禁。
- 观察期异常继续沿用现有自动回滚。
- 自主系统不得自行修改本服务、验收标准或提高自主等级。

## 四、现有模块接线

- `proactiveAgentTurn`：发送前创建短时效意图并过生活节律门；真实发送仍由 recordAndSend 完成；按真实结果结算意图。
- `mindLoop`：内部动作进入当日有限计划，不无限扩展；群聊不新增主动权限。
- `life-service`：维护 day/phase、少量内部目标、主动反馈冷却、夜间收尾；用户回复清除等待反馈状态。
- `memory-digest`：继续作为唯一稳定证据来源；continuity-service 消费其结果，不改写既有 digest。
- `evolution`：自修改由 autonomy-service 决定自动/审批/拒绝；写生产文件继续走行动账本、watch 和回滚。
- `health`：新增 actionIntents / continuity / autonomy / life 健康信号。

## 五、工作包与实施顺序

- WP0：冻结 v2.2.3 基线，核对近期改动与全量测试。
- WP1：action-intents + 主动消息接线 + 故障恢复。
- WP2：continuity-service + stable digest 消费 + scope/修订/自我上下文。
- WP3：life-service + 日计划、阶段、反馈冷却与夜间收尾。
- WP4：autonomy-service + evolution 风险决策 + 行动账本 + 沙盒/回滚门禁。
- WP5：健康、启动恢复、文档、跨系统故障矩阵与全量回归。

实施由主刀连续完成；每层先跑行为反例，再进入下一层；DSH 最后只读独立验收。

## 六、总验收矩阵（行为优先）

### 行动与恢复 A01–A10

- A01 意图写盘失败不得产生副作用。
- A02 同一 action_key 并发只执行一次。
- A03 非幂等执行中重启标 unknown，不自动重放。
- A04 只读/幂等任务仅在有明确策略时重试。
- A05 过期主动意图重启后不补发。
- A06 成功、失败、unknown 与 verified 证据分开。
- A07 私聊/群/local scope 不串。
- A08 主动发送失败不得记已发送或追加主动成功日志。
- A09 行动异常不得阻塞正常会话与感知。
- A10 异步任务不得因重启生成第二份相同任务。

### 认识与自我 C01–C10

- C01 只有 stable 证据能形成认识。
- C02 同证据重复消化幂等。
- C03 新证据增加确认记录，不重复制造相同认识。
- C04 私聊证据不得进入群或他人上下文。
- C05 冲突未解决标 contested，不参与决策。
- C06 修订保留 supersedes 链，旧认识不再注入。
- C07 过期认识不注入。
- C08 core 自我不可自改。
- C09 slow 自我缺多条证据时拒绝修订；重启后修订链仍在。
- C10 fast 状态到期失效，不篡改 slow/core。

### 生活节律 L01–L08

- L01 日目标数量有硬上限。
- L02 夜间/安静状态不主动发消息。
- L03 自主等级 0 时主动行为停止。
- L04 连续未回复逐级增加冷却。
- L05 用户回复后清除等待反馈状态。
- L06 重启保持同一天阶段、目标与冷却，不重新开始一天。
- L07 日期变化才新建日计划，旧未完成任务不无限滚存。
- L08 群聊不因本计划获得新的主动权限。

### 自主与自修改 G01–G10

- G01 非主人不能提升自主等级。
- G02 等级 1 只产提案，不自动写生产插件。
- G03 等级 2 仅低风险且验证充分的 self-* 可自动。
- G04 任何敏感能力或核心文件变更必须审批。
- G05 自主服务缺失/异常时自修改失败关闭为审批或拒绝。
- G06 自修改写盘失败不伪报成功，行动账本闭环。
- G07 冒烟失败不得写入生产插件目录。
- G08 观察期异常可回滚且不扩大权限。
- G09 不得通过自修改修改 autonomy-service 或验收矩阵。
- G10 自发目标/工具组合须有目标和结果证据，不以随机性冒充涌现。

### 系统 S01–S08

- S01 既有 v2.2.3 测试无回退。
- S02 插件结构、manifest 与依赖检查全绿。
- S03 新数据损坏时正常聊天可继续，新能力降级。
- S04 启动清单包含新服务 pending/unknown/degraded。
- S05 健康快照能报告新服务故障。
- S06 全部外部服务 mock，不触碰真实 QQ/桌宠/LLM。
- S07 doc-check 使用真实插件加载证据，不手改运行日志。
- S08 代码与模拟全绿仅 candidate_ready；真实长期观察后才 validated。

## 七、明确非目标

- 不开放核心文件自主改写。
- 不开放凭据、权限、回滚、自主等级与验收标准的自我修改。
- 不新增群聊主动权限。
- 不更换大模型，不扩大工具数量作为版本目标。
- 不承诺意识、人格同一性或不可控“电子生命”。
- 不在真实环境未验证时宣称连续存在已完全实现。
